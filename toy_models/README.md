# toy_models

Two self-contained scripts produce the M1 and M2 panels of the paper.

```
python simplest_toy_alignment_v10.py      # writes simplest_toy_alignment_v10.png + .csv
python single_neuron_headline_v12.py      # writes single_neuron_headline_v12.png + .csv
```

Outputs (PNG + CSV trace table) land next to the script.

Requirements: `numpy`, `matplotlib`. Tested on Python 3.10.
